# Sentiment Analysis Dashboard for Product Reviews

## Mandatory Features
- Enter Review
- Sentiment Classification
- Sentiment Score
- Review History
- Summary

## Technologies
HTML5, CSS3, JavaScript, Browser Local Storage.

## Run
Open `index.html` in a modern browser. Enter a review and click **Analyze Review**.

## Sample tests
Positive: "This product is excellent. I love the quality and it works perfectly."
Negative: "This product is terrible and I am very disappointed."
Neutral: "The product arrived today."

AI may be used for planning, coding assistance, debugging, testing guidance, and documentation. The student should review, test, and understand the implementation before submission.
